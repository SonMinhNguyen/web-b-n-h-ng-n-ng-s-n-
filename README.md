# 🌱 Website Bán Hàng Nông Sản

## Giới thiệu

Đây là đồ án xây dựng hệ thống **Website Bán Hàng Nông Sản**, hỗ trợ khách hàng mua sắm trực tuyến và quản trị viên quản lý toàn bộ hoạt động của hệ thống.

## Chức năng chính

### Khách hàng
- Đăng ký tài khoản
- Đăng nhập
- Quên mật khẩu
- Xem sản phẩm
- Tìm kiếm sản phẩm
- Truy xuất nguồn gốc
- Quản lý giỏ hàng
- Đặt hàng
- Thanh toán
- Áp mã giảm giá
- Theo dõi lịch sử mua hàng
- Đánh giá sản phẩm
- Quản lý hồ sơ cá nhân

### Quản trị viên
- Quản lý sản phẩm
- Quản lý khách hàng
- Quản lý đơn hàng
- Quản lý kho
- Quản lý khuyến mãi
- Kiểm duyệt đánh giá
- Xử lý yêu cầu trả hàng
- Xử lý hoàn tiền
- Báo cáo thống kê
- Quản lý nhật ký hệ thống
